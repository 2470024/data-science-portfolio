# Data Science Portfolio

大学で学んだデータサイエンスの知識を活用し、Pythonによるデータ分析や売上予測に取り組んだ成果物をまとめています。

## 1. 商品別売上予測

### 目的
過去の売上データを分析し、商品ごとの販売傾向を把握するとともに、今後の売上を予測することを目的としています。

### 使用技術
- Python
- pandas
- Google Colab
- 統計的分析・回帰分析

### 使用データ
- 売上履歴
- 商品情報
- 商品カテゴリ情報
- 商品価格・販売数量

### 分析内容
- データの読み込みと整理
- 商品ごとの販売傾向の分析
- 商品情報と売上データの活用
- 売上予測への取り組み

## 2. その他の分析課題
